# Sur Sanjeevani Trust — Website V3

A professional static website starter with an integrated bilingual information chatbot.

## Included
- Responsive homepage
- About, Music Therapy, Research, Education, IJIMT, Get Involved and Contact sections
- English-facing interface with chatbot information prepared for expansion to Hindi
- Phone/email links
- Mobile-friendly chatbot
- Conservative source-grounded wording based on the supplied Trust Deed

## Important before publishing
The supplied Trust Deed is an image-scanned PDF and some public details are not stated in it. Do not publish unverified claims about:
- ISSN or journal status
- courses currently running
- fees
- clinical outcomes
- registrations/approvals
- donation payment instructions
- office-bearers beyond what the Trust officially authorizes

## Low-cost launch
This static package can be hosted on a static hosting service such as GitHub Pages. A custom domain can be connected later.

## AI upgrade
For a true generative AI assistant, replace the rule-based `chatbot.js` with a small server-side API that retrieves only approved Trust documents and public FAQs. Keep API keys on the server, never inside browser JavaScript.

## Suggested production additions
1. Privacy notice and consent before collecting personal data.
2. Enquiry form with spam protection.
3. Official logo and approved photographs.
4. Hindi website copy.
5. Official IJIMT information after confirmation.
6. Donation/payment gateway only after Trust-side verification.
